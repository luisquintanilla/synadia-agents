# Integrations

.NET integrations that build on the core SDKs in `client-sdk/dotnet` and `agent-sdk/dotnet`.

- [`agent-framework/`](agent-framework/) — `Synadia.AI.Agents.AgentFramework`: use NATS agents as Microsoft Agent Framework `AIAgent`s (`NatsAIAgent`) and serve any `AIAgent` on NATS (`ServeAIAgent`).
